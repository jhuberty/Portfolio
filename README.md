# Jackson Huberty Engineering Portfolio

## Live Site

https://jhuberty.github.io/Portfolio/

## Overview

This repository contains the engineering portfolio of Jackson Huberty, a Cal Poly BioResource and Agricultural Engineering student. It highlights hands-on mechanical design, CAD, manufacturing, machining, welding, agricultural equipment, testing, and field operations.

## Featured Work

- **Quarter Scale Tractor** — Structural design, fabrication, CAD, hydrostatic systems, and preliminary frame-rail analysis.
- **Agave Harvester Senior Project** — Design, fabrication planning, and iterative development of a chopping-head structure for an agave-harvesting concept.
- **Machining and Fabrication** — CNC plasma cutting, manual/CNC machining, welding, shop equipment maintenance, and student training.
- **Agricultural Equipment and Field Work** — Field operations, irrigation, agricultural implements, and equipment repair.

The portfolio also represents engineering tools and skills including SolidWorks, CNC plasma cutting, machining, welding, fabrication, and agricultural equipment operation.

## Run Locally

1. Download or clone this repository.
2. Open `index.html` in a web browser.

Optionally, start a local server:

```powershell
python -m http.server 8000
```

Then view the site at http://localhost:8000.

## Updating the Portfolio

- Main site content is in `index.html`.
- Detailed project pages are in `projects/`.
- Styling is in `styles.css`.
- Interactions, mobile navigation, and image lightbox behavior are in `script.js`.
- Images are organized in `assets/images/` by project.
- The resume PDF is stored in `resume/`.

## Notes

This portfolio is actively updated as projects progress and new test results, photos, and fabrication work become available.
